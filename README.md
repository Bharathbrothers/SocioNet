# Sociology Pro - UGC NET/JRF Solved Papers (2011-2025)

This zip contains the complete pre-built production application ready for **GitHub Pages**, **Vercel**, **Netlify**, or local offline usage.

## Method 1: Deploy on GitHub Pages (Instant Drag & Drop)
1. Create a repository on GitHub (e.g. `ugc-net-sociology`).
2. Extract this zip file.
3. Upload all extracted files and folders (`index.html`, `assets/`, `manifest.webmanifest`, etc.) directly into your repository.
4. Go to **Settings > Pages** on your GitHub repository.
5. Under **Build and deployment > Branch**, select `main` and folder `/(root)`, then click **Save**.
6. Your app is live at: `https://<YOUR-GITHUB-USERNAME>.github.io/ugc-net-sociology/`!

## Method 2: Deploy on Netlify / Vercel (10 Seconds)
- **Netlify**: Go to https://app.netlify.com/drop, drag-and-drop the extracted folder. Done!
- **Vercel**: Import your GitHub repo, Framework: Vite, Output Directory: dist. Click Deploy!
